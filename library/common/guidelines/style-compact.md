# Style Guidelines (Compact)

## Writing

- Use short, direct sentences.
- Prefer bullet lists over long paragraphs.
- Keep headings in Title Case.

## Naming

- Use kebab-case for new files and folders.
- Keep names short and descriptive.
- Avoid abbreviations unless they are standard in the domain.

## Code

- Keep diffs small and focused.
- Follow the repo's existing formatting and lint rules.
- Add `.desc.md` files next to new source files.
