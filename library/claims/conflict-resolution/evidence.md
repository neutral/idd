# Evidence Capture

Capture this claim type in the shared Arc evidence shape: claim, context or
method, observations and raw artifacts, and verdict.

## Claim

- state the conflicting sources or layers
- record the disagreement that mattered
- record the reconciliation action or deferral

## Methodology References

- record the claim type folder path
- link `arc.md`, relevant step refs, and the evidence index
- link decision refs or run-ledger entries that preserved the reconciliation

## Method Or Context

- explain how the conflict was discovered
- record whether it was resolved in-step, deferred, or escalated

## Observations

- record the conflicting sources
- record why the chosen reconciliation path controlled the run
- record any remaining open point or limit on the resolution

## Raw Artifacts

- conflicting refs
- decision artifacts
- approval notes when relevant

## Verdict Guidance

- `supported`: the conflict and reconciliation path are explicit and inspectable
- `mixed`: a usable path exists but part of the conflict remains open
- `open`: the conflict is still awaiting clarification or approval
- `incomplete`: the conflict thread exists but lacks enough support yet
- `failed`: the Arc hid or silently overrode a material conflict

## Evidence Thread Rules

- create a new item when an unrelated conflict needs separate handling
- enrich the existing item when the same conflict gains more support
- do not mix ordinary authority choice with a full conflict thread unless both
  are still one inspectable question

## Closeout Conditions

- the conflict is explicit
- the reconciliation path is explicit
- any durable outcome has a decision-home when needed
