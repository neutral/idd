# Evidence Capture

Capture this claim type in the shared Arc evidence shape: claim, context or
method, observations and raw artifacts, and verdict.

## Claim

- name the Arc objective or scoped work outcome
- link the intent and blueprint refs that define it
- record any material non-goals or narrowing

## Methodology References

- record the claim type folder path
- link `arc.md`, the relevant step refs, and the evidence index
- link run-ledger entries that refined or re-stated the target

## Method Or Context

- explain how the target was chosen or confirmed
- record whether the Arc inherited the target directly from the user request or
  refined it during execution

## Observations

- record the exact outcome the Arc is serving
- record nearby work that was explicitly left out
- record any target shift that changes interpretation

## Raw Artifacts

- relevant intent files
- relevant blueprint files
- step summaries or decisions that restated the target

## Verdict Guidance

- `supported`: the target is explicit and the Arc stayed aligned to it
- `mixed`: the target exists but shifted or stayed partly vague
- `open`: the target is active but still needs clarification
- `incomplete`: the target thread exists but not enough support is recorded yet
- `failed`: the Arc materially diverged from the claimed target

## Evidence Thread Rules

- create a new item when the scoped target changes materially
- enrich the existing item when the same target gains more support or
  clarification
- do not mix target definition with verification or governance posture

## Closeout Conditions

- the final Arc target is explicit
- the defining refs are recorded
- any narrowing that changes interpretation is preserved
