# Evidence Capture

Capture this claim type in the shared Arc evidence shape: claim, context or
method, observations and raw artifacts, and verdict.

## Claim

- state the overall Arc posture
- state the main factors that force that posture
- state what would need to change for the posture to improve

## Methodology References

- record the claim type folder path
- link `arc.md`, relevant step refs, and the evidence index
- link the supporting evidence items that drive the posture

## Method Or Context

- explain when the posture was assigned
- record whether it emerged during execution, proof, or final validation

## Observations

- record the current overall posture
- record the main limiting factors
- record the practical consequence for trust or next action

## Raw Artifacts

- supporting evidence items
- final-validation notes
- blocking or carry-forward artifacts

## Verdict Guidance

- `supported`: use only when the overall Arc posture is now cleanly supported
- `mixed`: the Arc landed value but remains only partly acceptable
- `open`: the posture is still under evaluation or waiting on input
- `incomplete`: the posture thread exists but is not yet inspectable enough
- `failed`: the Arc is blocked or materially unsuccessful in its current state

## Evidence Thread Rules

- create a new item when unrelated limiting factors need separate handling
- enrich the existing item when the same posture becomes clearer
- do not mix detailed verification logs or governance evidence into this thread

## Closeout Conditions

- the current Arc posture is explicit
- the main limiting factors are linked to supporting evidence
- the next action or carry-forward trigger is recorded
