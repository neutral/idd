# IDD Workflow

Use this file as a menu-based entrypoint. Pick the next option from user input.
If user input is ambiguous, ask a short clarifying question before proceeding.

## Menu

1. Intent bootstrap or refresh
   - Ensure `intents/` structure and starter artifacts are in place using `overview.md`, `artifact-types/overview.md`, and `content-organization/file-organization-navigation.md`.
2. Intent or blueprint refinement
   - Update goals/features/scenarios/behaviors/assurances/decisions/definitions to remove ambiguity and improve implementability.
3. Procedure-driven implementation step
   - Run procedures from `.methodologies/idd/library/procedures/` and persist durable outputs back to Intent, Blueprint, and Code artifacts (including description files).
